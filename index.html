Consistent Hashing & Ring Rebalancing

            
Why modulo hashing `hash(key) % N` kills your cache on node addition

          


          
          

            

              ⚡ The Core Problem:
            

            
With standard mod hashing, adding 1 server invalidates ~N/(N+1) keys (almost 99% cache miss storm!).

            
            

              💡 The SDE-2 Solution:
            

            
Map both nodes and keys to a 360° hash ring. Keys route clockwise to nearest node. Adding a node moves only K/N keys. Virtual nodes prevent hot-spots.
